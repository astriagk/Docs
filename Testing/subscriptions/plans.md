# Subscription Plans

## Plan Structure

Each plan contains the following information:

- **Plan Name**: Name of the subscription plan
- **Plan Type**: Monthly, Quarterly, or Yearly
- **Pricing Model**: Flat (fixed price), Per Kid (price per child), or Base + Per Kid (base fee + per child)
- **Price**: Base/flat price
- **Per-Kid Price**: Price charged per additional child (if applicable)
- **Min Kids**: Minimum number of kids allowed on plan
- **Max Kids**: Maximum number of kids allowed on plan (null for unlimited)
- **Features**: List of included features with keys and labels
